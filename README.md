## 🚀 Kurulum & Çalıştırma

### Gereksinimler

- [Node.js](https://nodejs.org/) v18+
- [pnpm](https://pnpm.io/) (önerilir)

### Adımlar

```bash
# 1. Repoyu klonlayın
git clone https://github.com/saidbayraqtars/spacexpirate.git
cd spacexpirate

# 2. Bağımlılıkları yükleyin
pnpm install

# 3. Geliştirme sunucusunu başlatın
pnpm dev
```

Tarayıcınızda **[http://localhost:3000](http://localhost:3000)** adresini açın.

### Production Build

```bash
pnpm build
pnpm start
```
